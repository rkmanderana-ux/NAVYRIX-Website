NAVYRIX

NAVYRIX NoRoot Firewall is a local Android application firewall designed to give users control over network access on their device.

About NAVYRIX

NAVYRIX NoRoot Firewall provides application-level network access control on Android devices without requiring root access.

Firewall traffic processing is performed locally on the device. NAVYRIX does not operate a remote VPN server for routing user traffic.

Privacy

NAVYRIX is designed with local-first firewall processing. Information handling depends on the features enabled by the user and the external services used by the application.

A complete privacy policy will be published here before public release.
